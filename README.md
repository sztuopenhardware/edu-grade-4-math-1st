## 🚀 部署到 GitHub Pages 教程（只需 3 步）

本项目已配置好相对路径与 `.nojekyll`、`.gitignore`（默认自动忽略体积较大的本地原始 PDF 课本文件），可直接推送部署：

1. 在 GitHub 上新建一个公开仓库（例如命名为 `grade4-math`）。
2. 在本文件夹打开终端，执行以下命令上传代码：
   ```bash
   git init
   git add .
   git commit -m "feat: 四年级上册数学奇妙冒险岛自学网站"
   git branch -M main
   git remote add origin https://github.com/你的用户名/grade4-math.git
   git push -u origin main
   ```
3. 打开 GitHub 仓库页面，依次点击 **Settings（设置）** ➔ 左侧菜单 **Pages** ➔ 在 **Build and deployment / Branch** 下选择 **`main`** 分支和 **`/ (root)`** 目录，点击 **Save**。
4. 等待约 1 分钟，即可通过 `https://你的用户名.github.io/grade4-math/` 在手机、iPad 或电脑上随时访问啦！
